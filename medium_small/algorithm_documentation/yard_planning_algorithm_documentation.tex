\section{总体说明}

\code{medium_small} 使用两层求解流程：
\begin{itemize}
  \item 中计划在箱区层面分配粗属性组箱量，先由 SCIP 构造完整箱区分配，再执行中小计划结构化反馈轮；命令行 \code{--iterations>0} 时继续启用模拟退火搜索。
  \item 小计划先按中计划箱区分布做严格继承落贝；严格继承不可行时，直接按贝位硬约束执行 repair 构造，并用小计划实际区域分布对最终中计划输出做一致性对齐。
\end{itemize}

当前数据读取、中计划箱量计算、小计划资料箱读取、大计划继承配额、目标航次推导和规划窗口口径与列生成目录保持一致。默认数据预设为 \code{--dataset 0519}：数据目录为仓库根目录下的堆存计划测试数据20260519，大计划文件为 \code{large/outputs_large/latest_run/allocation.csv}。预设 \code{--dataset 0508} 使用 \code{test_data/pro_test_data_0508} 和 \code{flat_full_yard_plan_scip/full_plan_outputs/run_scip_visual_20260521_001/outputs_large/latest_run/allocation.csv}。命令行中的 \code{--data-dir} 和 \code{--big-plan} 可以覆盖预设。

默认 0519 原始数据口径的规划时刻为 \code{2026-05-19 09:30:00}。命令行显式给定 \code{--planning-time} 时使用该覆盖值；若显式传入包含 \code{input_data.json} 的数据目录且未指定 \code{--planning-time}，则读取 JSON 中的 \code{planning_time}。默认规划窗口长度为 24 小时。若命令行没有给定 \code{--voyages}，程序从当前大计划中筛选规划日期的 \code{OF} 行，并将这些行对应的航次作为本次目标航次。

\section{输入口径}

\subsection{数据目录}

默认 0519 数据目录为原始数据目录堆存计划测试数据20260519。程序从该目录读取 \code{bay_slots_detail.parquet}、\code{tops_plan_info.parquet}、\code{container_info_\{voyage\}.parquet}、\code{predict_data_\{voyage\}.xlsx}、箱区功能表和船期 CSV。若通过 \code{--data-dir} 指向封装 JSON 数据目录，读取器仍兼容 \code{input_data.json}。

\subsection{大计划}

大计划默认来自 \code{--dataset} 预设，也可以用 \code{--big-plan} 指定。支持的主要字段形式为：
\begin{itemize}
  \item \code{voy_id, flow, area_no, size, planned_qty}
  \item \code{voyage_id, area_no, qty_20, qty_40[, plan_date]}
  \item \code{voyage_id, area_no, planned_boxes[, size_mode, plan_date]}
\end{itemize}

当前中小计划默认只继承目标日期、目标航次、\code{OF} 流向的大计划行。关闭箱区为硬禁止。大计划行所在箱区会加入对应流向功能集合，使继承行可以作为候选箱区。45ft 箱在继承大计划箱区配额时归入 40ft 大计划尺寸口径；小计划落贝仍按真实 45ft 规则处理。

\subsection{堆场容量}

\code{bay_slots_detail} 提供每个贝位的可用槽位、\code{YBY_ENABLECSIZECD} 尺寸适放能力、已有箱尺寸、已有箱高、已有箱卸港和已有箱号。若 \code{YBY_ENABLECSIZECD} 为空，代码按 20/40/45 均可放处理。

每个贝位同时维护：
\[
Cap_b^{phy},
\quad
Cap_{bs},
\]
其中 \(Cap_b^{phy}\) 是贝位物理空槽上限，\(Cap_{bs}\) 是该贝位对尺寸 \(s\) 的可放上限。40ft 和 45ft 的落贝还需要有效的大贝配对 \code{large_bay_partner_key}，占用时同时占用两个小贝的物理容量。

\subsection{TOPS 与错放贝位}

非目标航次的有效 TOPS 区间会在容量统计前整贝关闭；目标航次自身的 TOPS 记录不关闭。错放贝位剔除阈值由 \code{--misplaced-bay-exclusion-ratio} 控制，默认 \(2/3\)。若某贝位中当前仍占用的箱子与箱区功能不匹配，且错放箱量超过该贝位原始总槽位数的阈值，则该贝位不参与中计划容量和小计划落贝。

\section{中计划需求}

\subsection{粗属性组}

中计划粗属性组为：
\[
g=(v,f,p,s),
\]
其中 \(v\) 为航次，\(f\) 为流向，\(p\) 为卸港，\(s\in\{20,40,45\}\) 为真实尺寸。中计划输出粒度为：
\[
(v,f,p,s,a),
\]
其中 \(a\) 为箱区。

\subsection{规划阶段与比例}

设航次开港时间为 \(r_v\)，总进箱结束时间为 \(e_v\)，当前规划时刻为 \(t_0\)，规划窗口长度为 \(H\)。当前代码用 \code{planning_stage_window} 计算本轮窗口和累计比例：
\[
\rho_v=
\begin{cases}
0, & t_0<r_v,\ t_0+H<r_v,\\
0.70, & t_0<r_v,\ t_0+H\ge r_v,\\
0.70, & r_v\le t_0<r_v+H,\\
0.90, & r_v+H\le t_0<r_v+2H,\\
1.00, & t_0\ge r_v+2H.
\end{cases}
\]
若存在总进箱结束时间，窗口结束点会截断在进箱结束时间以内。

\subsection{预测、资料箱、在场箱和大计划上限}

对每个航次、流向、尺寸，代码先读取预测箱量 \(P_{fsp}\)，再按比例 \(\rho_v\) 用最大余数法生成港口目标 \(R_{fsp}\)。资料箱箱量 \(D_{fsp}\) 来自资料箱表。二者比较发生在扣减已在场箱之前：
\[
\sum_p D_{fsp}
\quad\text{与}\quad
\sum_p R_{fsp}.
\]
若资料箱总量更大，则该航次、流向、尺寸使用资料箱港口分布；否则使用比例预测港口分布。随后扣减当前仍在堆场中的同航次、同流向、同尺寸、同卸港箱量 \(Y_{fsp}\)：
\[
M_{fsp}=\max(0,S_{fsp}-Y_{fsp}).
\]

最后按大计划 \code{new\_qty} 构造航次、流向、大计划尺寸口径上限。默认目标流向为 \code{OF}；真实 45ft 需求使用 40ft 大计划尺寸池。若需求超过大计划上限，则用最大余数法按现有需求比例缩放到上限内。生成的正箱量成为 \code{ProblemData.groups}。

\section{小计划资料箱}

小计划资料箱默认来自原始数据目录中的 \code{container_info_\{voyage\}.parquet}。读取后先用堆场快照中的箱号和箱 ID 剔除当前已经在堆场中的资料箱，再按细属性聚合：
\[
h=(v,f,p,s,\eta,w,\sigma,r),
\]
其中 \(\eta\) 为箱高，\(w\) 为重量等级，\(\sigma\) 为显式特殊积载代码，\(r\) 为预配/预留标记。当前数据没有显式特殊积载标记时，代码不根据冷藏、危险、超限等业务字段推断特殊积载。

小计划只规划当前未进场资料箱，不生成列生成内部的预测兜底小计划组。中计划需求中未被资料箱覆盖的部分仍保留在中计划层面。

\section{中计划模型}

\subsection{变量与硬约束}

中计划变量为：
\[
x_{ga}\in \mathbb{Z}_{\ge 0},
\]
表示粗属性组 \(g\) 在箱区 \(a\) 的箱量。代码还隐式记录未放箱量：
\[
u_g=d_g-\sum_a x_{ga}\ge 0.
\]

候选箱区必须满足：
\begin{itemize}
  \item 箱区在大计划中属于对应航次--流向的已分配箱区，或箱区功能支持流向 \(f\)。
  \item 箱区物理容量和真实尺寸容量均为正。
\end{itemize}

所有中计划分配满足：
\[
\sum_g x_{ga}\le Cap_a^{phy},
\]
\[
\sum_{g:s(g)=s}x_{ga}\le Cap_{as},
\]
大计划箱区--尺寸配额 \(Q_{vfa\bar{s}}\) 是目标函数中的软参考模式，不作为中计划移动的硬上界。每个中计划粗属性组必须完整分配到候选箱区，箱区物理容量和真实尺寸容量作为硬约束检查。若初始构造无法给出完整可行分配，程序停止本轮求解并在初始解诊断中写出缺口。

\subsection{初始解}

中计划初始分配优先使用 PySCIPOpt/SCIP 构造一个完整可行的箱区分配。SCIP 模型包含组需求满足、箱区物理容量和箱区真实尺寸容量约束；大计划箱区--尺寸配额通过正负偏差变量进入目标函数，并与泊位距离、作业窗口和集中拆分成本共同决定初始解偏好。

若 PySCIPOpt/SCIP 不可用或 SCIP 模型没有可用解，代码执行多轮确定性贪心兜底。默认尝试 30 轮，策略在原始顺序、难组优先、大需求优先、紧容量优先、小组优先、随机顺序，以及 weighted/capacity/concentrated 分配方式之间切换。只有完整满足所有粗属性组需求并通过硬约束检查的分配才能作为初始解；若所有轮次仍存在缺口，则中计划初始化失败并停止本轮求解。

\subsection{中小计划结构化反馈}

SCIP 初始分配完成后，程序默认执行 \code{--medium-small-feedback-iterations=10} 轮中小计划结构化反馈。每一轮先用当前中计划构造小计划：严格继承可行时记录严格可行结果；严格继承不可行时执行 direct repair。repair 得到的小计划区域分布会汇总成航次--流向--箱区--大计划尺寸口径的 learned cap，并以 \code{medium_small_feedback_cap_penalty} 进入下一轮中计划 SCIP/SA 能量函数。

反馈轮按小计划未放箱、strict/repair 可行状态、与中计划一致性缺口、repair 额外补箱量和中计划能量共同排序，选择最好的中计划作为后续退火或最终小计划构造的起点。命令行 \code{--medium-small-feedback-iterations=0} 时跳过该阶段。

\subsection{模拟退火}

退火状态是所有 \(x_{ga}\) 的集合。每轮扰动随机选择一个已有箱量的粗属性组和源箱区，把一批箱量移动到另一个候选箱区；若外部修正产生临时缺口，也会先尝试把缺口放入仍有容量的候选箱区。候选状态必须继续满足箱区容量、尺寸容量和候选箱区约束；大计划配额偏差、fallback tier、小计划反馈和小计划可行性通过能量函数调节。

接受准则为：
\[
\Pr(\text{accept})=
\begin{cases}
1, & \Delta E\le 0,\\
\exp(-\Delta E/T), & \Delta E>0.
\end{cases}
\]
温度按指数方式从 \(T_0=80.0\) 下降到 \(T_f=0.2\)。命令行默认 \code{--iterations=0}，即只执行 SCIP 初始解、结构化反馈和最终小计划构造；传入正迭代次数时启用模拟退火。

终端进度日志默认每 \code{--log-every=1000} 轮输出一次，打印总能量、当前最优能量、温度和接受次数。

当 \code{--small-plan-check-every>0} 且退火迭代数为正时，退火过程中每隔指定轮数对当前 best 分配执行小计划闭环检查。检查日志包含 \code{strict_feasible} 和 \code{repair_feasible}。
\code{strict\_feasible=True} 表示中计划区域分布可被小计划严格继承；\code{strict\_feasible=False, repair\_feasible=True} 表示严格继承不可行，但直接贝位 repair 可构造可行小计划。repair 成功时，小计划实际使用的箱区分布会转换为新的中计划 assignment，并写回当前退火状态和 best 状态继续搜索。日志中的 \code{method=in_place_capacity_checked} 表示在中计划容量硬约束内完成同粗属性组区域迁移；\code{method=counter_projection} 表示按 repair 后的中小一致计数投影回中计划状态，并在日志中同时给出 \code{medium_hard_feasible}。

\subsection{中计划目标}

中计划能量函数包含以下项：
\begin{itemize}
  \item 小量粗属性组集中堆存。若 \(d_g\le\)\code{medium_concentrated_group_threshold}，默认阈值 26，则惩罚使用额外箱区和非最大箱区碎片，默认权重分别为 1500 和 80。
  \item 大量粗属性组在已使用箱区之间均衡，并惩罚低于 \code{medium_large_group_min_area_boxes=10} 的小碎片箱区，默认碎片权重 1500。
  \item 总的大计划箱区--尺寸模式偏离，默认权重 30。
  \item 大计划继承 fallback tier 惩罚，默认基础权重 500；同航次同尺寸有剩余配额的箱区优先，非同航次但属于大计划覆盖箱区次之，其他功能可用候选箱区最后。
  \item 中小计划 learned cap 反馈惩罚，默认权重 20000，用于让中计划避开 repair 证明难以落贝的箱区--尺寸容量组合。
  \item 航次箱区到泊位距离，默认权重 3，按距离/100 进入能量。
  \item 规划窗口内其他装船作业避让，默认惩罚 1000；窗口后 24 小时内有后续装船作业时给予偏好奖励，默认 1000。
  \item 小计划严格继承失败反馈惩罚。严格继承不可行但 direct repair 可行时，记录到 \code{small_plan_strict_area_feedback}，默认权重 \code{small_plan_strict_feedback_penalty=45}。
  \item 小计划 repair 失败反馈惩罚。严格继承和 direct repair 均不可行时，记录到 \code{small_plan_area_feedback}，默认惩罚为 \code{small_plan_feedback_penalty=250} 乘以 \code{small_plan_repair_failure_feedback_multiplier=4}。
  \item 小计划 proxy 评分，用于估计资料箱落贝容量、尺寸--箱高容量、45ft 边贝容量和连续 6 小贝冲突风险；命令行默认 \code{--small-plan-proxy-every=0}，结构化反馈开启时通常不启用该轻量 proxy。
\end{itemize}

结构化 feedback、可选 SA 内 strict feedback、repair feedback、learned cap 和最终 repair 对齐共同作用于中计划箱区选择：结构化 feedback 在退火前反复求解 SCIP 中计划，learned cap 使中计划远离小计划落贝困难的区域组合，SA 内反馈在启用退火和周期检查时即时调整搜索状态，最终 repair 对齐保证输出中计划覆盖小计划实际区域用量。

\section{小计划构造}

\subsection{严格继承}

中计划 assignment 先汇总为 \((v,f,p,s,a)\) 输出计数，并在小计划严格继承阶段进一步聚合为 \((v,f,s,a)\) 箱区尺寸配额。资料箱细分组按 \((v,f,p,s)\) 分批处理，但继承上界在 \((v,f,s,a)\) 层面消耗。这样可以处理预测卸港分布与资料箱卸港分布不一致的情况。

对每个细分组，候选箱区必须有剩余中计划继承配额、真实尺寸容量和尺寸--箱高可落容量。排序优先级为 45ft、20ft、40ft；同尺寸下优先处理可选箱区少、可落容量紧、需求量大的组。严格继承成功时，输出诊断中的 \code{small_plan_construction_mode} 为 \code{strict_medium_area_inheritance}。

\subsection{Direct repair}

严格继承无法满足全部资料箱时，小计划执行直接贝位 repair。repair 将中计划箱区配额作为排序偏好，而非硬上界，在所有业务可用箱区和贝位中寻找可行落位。候选贝位排序优先级为：
\begin{enumerate}
  \item 同 \((v,f,p,s,a)\) 的中计划区域仍有剩余 exact quota。
  \item 同 \((v,f,s,a)\) 的中计划区域仍有剩余 broad quota。
  \item 箱区属于对应航次--流向的大计划使用区域。
  \item 其它功能可用箱区。
  \item 当前贝位可一次容纳该细分组剩余箱量。
  \item 连续 6 小贝区块亲和、贝位属性亲和、既有箱卸港一致、fallback 贝位靠后和贝位顺序。
\end{enumerate}

repair 成功时，输出诊断中的 \code{small_plan_construction_mode} 为 \code{direct_bay_repair}。最终输出阶段用 repair 后的小计划实际 \((v,f,p,s,a)\) 使用量修正中计划计数：优先从同 \((v,f,p,s)\) 的其它箱区平移中计划箱量，平移不足时按小计划实际使用量补齐中计划输出。该计数修正确保 \code{medium_plan.csv} 覆盖 \code{small_plan.csv} 的区域用量，并在 \code{small_plan_medium_repair_added_boxes} 中记录无法通过同组平移补齐而额外补入的箱量。

严格继承和 direct repair 均无法构造小计划时，本轮中计划会记录 repair 失败反馈并触发重试或已有可行中计划回退。最终成功输出的结果满足 \code{medium_unplaced_boxes=0} 和 \code{small_unplaced_boxes=0}；若输入容量本身不足，未放箱诊断字段保留对应缺口。

\subsection{贝位硬约束}

小计划贝位构造满足：
\begin{itemize}
  \item 贝位真实尺寸容量和物理容量不超限。
  \item 40ft/45ft 需要有效大贝配对，且同时占用配对贝物理容量。
  \item 同一贝位或大贝 footprint 内不混尺寸。
  \item 同一贝位或大贝 footprint 内不混箱高。
  \item 20ft 不放箱区两头贝。
  \item 45ft 必须放箱区两头贝。
  \item 若某箱区存在 45ft 资料箱分配，两头贝只供 45ft 使用。
\end{itemize}

\subsection{贝位偏好}

小计划启发式按排序选择贝位。主要偏好为：
\begin{itemize}
  \item 同一细属性亲和键优先进入同一连续 6 小贝区块和同一贝位。
  \item 同一粗属性键 \((v,f,p,s)\) 的细分组优先共享区块。
  \item 既有箱卸港与资料箱卸港一致的贝位优先。
  \item fallback 贝位靠后。
  \item 显式特殊积载和预配/预留标记保留隔离偏好。
\end{itemize}

连续 6 小贝区块由箱区内按顺序的 6 个小贝构成。当前识别规则要求区块内至少包含两个不重叠的大贝配对，并且剩余小贝中至少两个可放 20ft。

  \item \code{small_unplaced_boxes}、\code{small_unplaced_by_group}：小计划未放箱。
  \item \code{concentration_penalties}：与列生成同口径的集中/碎片参数。
